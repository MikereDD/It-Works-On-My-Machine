It-Works-On-My-Machine

The working systems repository for Netzach and Arakiel.

If it defines or helps operate Netzach or Arakiel, it belongs here. If it grows into a standalone project, it graduates out.

01

NETZACH

DEVELOPMENT WORKSTATION

Windows development, builds, testing, media tooling, dotfiles, PowerShell automation, and the prototypes that start larger ideas.

  • PowerShell + profile.d
  • Vim configuration
  • Admin + personal tools
  • Build / test / create
02

ARAKIEL

SERVER / AUTOMATION NODE

Arch Linux on Raspberry Pi 5: always-on services, shell environments, tmux, system administration, networking, and automation.

  • Bash + Zsh
  • tmux + Vim + i3
  • Pi / network administration
  • Services + automation

SHARED

Portable scripts, tools, dotfiles, and templates that genuinely belong to both systems.

EXPERIMENTS

3D printing, Android, games, prototypes, and whatever strange idea becomes useful next.

LINEAGE

Useful ancestors stay. PowerShell prototypes can remain even after their descendants graduate into standalone repositories.

WORKFLOW

Discover → Build → Use → Refine → Graduate.
