## ✨ What It Is

Cloud Player is an experimental, provider-first media player built inside the **It Works On My Machine** project.

It started from the pCloudTV idea, but Cloud Player is designed to grow beyond a single provider.

> **Your media belongs to you — not your storage provider.**

---

## ☁️ Provider-First Design

## 🎵 Visualizer Permission Note

The real-time audio visualizer uses Android audio capture APIs and requires the **Microphone** permission.

On Android TV, grant it from:

```text
Settings -> Apps -> Cloud Player -> Permissions -> Microphone
```

Without that permission, Android may block live audio spectrum data and the visualizer may fall back to synthetic motion.
